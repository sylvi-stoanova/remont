# Завършена демонстрационна версия

Едностраничен сайт на български за измислена строителна и ремонтна фирма. React, Three.js и GSAP; статично публикуване, без backend и без Higgsfield.

## Преглед и компилиране

Изисква Node.js 22.18+ или 24.

```sh
npm ci
npm run build
npm run preview
```

Преглед: http://127.0.0.1:4319

`dist/` съдържа готовите статични файлове. Използвайте HTTP сървър, а не file://.

## Визуален подход

- Начален екран, галерия и трите сравнения използват самостоятелни фотографски изображения. Няма моделирани Three.js помещения.
- Преди/след кадрите са оригинални AI визуализации, а не документални снимки. Версията „преди“ е редакция на съответния завършен кадър със запазени архитектура, перспектива и отвори. Генеративният процес не гарантира математическо съвпадение на всеки пиксел.
- Един 3D момент: фотография на баня → приближаване към плочките → последователно разделяне на пет слоя → пауза → събиране. Цялата последователност е обратима при скрол.
- PBR камък, normal/bump/roughness/AO карти, реален релеф на лепилото, зидария, осветление и сенки. Desktop добавя SSAO и слаба дълбочина на рязкост. Mobile използва по-ниска резолюция и пропуска тежката постобработка.
- Намаленото движение показва статична материална композиция. При недостъпен WebGL, грешка на 3D модула или текстурата остава фотографски fallback с текста.

## Контакти и форма

В `src/main.jsx` заменете `[ТЕЛЕФОН]` и `[EMAIL]` с реални стойности, когато адаптирате демонстрацията за фирма. Връзките са tel: и mailto:, но placeholders не са действителни контакти. Формата е изрично демонстрационна, не изпраща и не съхранява данни.

## GitHub Pages

1. Качете съдържанието на този проект в GitHub repository, със src, public, package.json, package-lock.json, build.mjs и .github на най-горно ниво.
2. Settings → Pages → Source: GitHub Actions.
3. Push към main или ръчно стартирайте workflow „Publish static website“.

Workflow компилира и публикува само `dist/`. Относителните пътища работят и под repository subpath. Не е извършено външно публикуване и не е избрано repository.

## Проверки

Вижте QA.md за действително изпълнените проверки и ограниченията им. Тестовият harness не се включва в готовия статичен пакет.

## Основни файлове

- `src/main.jsx` — съдържание, плъзгач и scroll последователност.
- `src/scene.jsx` — единствената 3D сцена с материалните слоеве.
- `src/style.css` — desktop/mobile и reduced-motion стилове.
- `public/images/*-v3.jpg` — шест проектни изображения и каменна текстура.
- `build.mjs` — Rollup/Babel build; премахва само проверената генерирана dist директория и не включва старите assets.

Шрифтът се зарежда от Google Fonts с локален Arial fallback и display=swap.
